# SQL & Excel Data Analysis Assignment

## 📌 Project Overview

This project demonstrates practical skills in **SQL and Microsoft Excel** using an employee dataset. The project covers database operations, data filtering, aggregation, joins, subqueries, Excel data analysis, lookup functions, Pivot Tables, and charts.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- Microsoft Excel
- SQL
- Pivot Tables
- Excel Functions

## 📂 Project Tasks

### Task 1 – Introduction to Databases & SELECT
Used SQL `SELECT` statements to retrieve all employee records, selected columns, and customized column names using aliases.

### Task 2 – WHERE, ORDER BY & Aggregate Functions
Used `WHERE` to filter employee records and `ORDER BY` to sort data. Applied `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()` to summarize employee salary data.

### Task 3 – GROUP BY & HAVING
Grouped employees based on their departments and used aggregate functions to calculate department-level statistics. `HAVING` was used to filter grouped results.

### Task 4 – SQL JOINS
Used `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN` to combine employee and department information from related tables.

### Task 5 – SQL Subqueries
Used subqueries to identify employees earning above the average salary, employees with the maximum salary, and employees belonging to a specific department.

### Task 6 – Excel Data Formatting, Sorting & Filtering
Formatted the employee dataset in Excel and performed sorting and filtering to organize and analyze employee information.

### Task 7 – Conditional Formatting & Excel Functions
Applied conditional formatting and used `IF()`, `COUNTIF()`, and `SUMIF()` to categorize employees and summarize department-level salary information.

### Task 8 – VLOOKUP & XLOOKUP
Used `VLOOKUP()` and `XLOOKUP()` to retrieve department information based on Department IDs and connect data between the Employees and Departments tables.

### Task 9 – Pivot Table & Charts
Created a Pivot Table to summarize employee salary information by department and created a **Total Salary by Department** chart for visual comparison.
